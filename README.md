## Libraries and tools

| Project | What it does |
| --- | --- |
| [DisposableEvents](https://github.com/Hissal/DisposableEvents) | Pub/sub events that return an `IDisposable` subscription. Disposing the handle unsubscribes, so there is no `-=` to forget. On NuGet. |
| [Closures](https://github.com/Hissal/Closures) | Closure structs that capture state and a delegate without allocating on the heap. Benchmarked, on NuGet, and usable in Unity. |
| [HCommons](https://github.com/Hissal/HCommons) | Pooled buffers, math helpers and result/option types for .NET. On NuGet. |
| [UnityLayerRemapper](https://github.com/Hissal/UnityLayerRemapper) | Remaps layer indices across a Unity project's scenes, prefabs and assets. It shows every change before it writes anything. |
| [UnityTypeSerializer](https://github.com/Hissal/UnityTypeSerializer) | Lets the Unity Inspector store `System.Type` references, including constructed generic types. |
| [InspectorEvents](https://github.com/Hissal/InspectorEvents) | Adds serialization options for events in the Unity Inspector. |
| [mutation-designer](https://hissal.github.io/mutation-designer/) | A browser app our designers use to write and compare upgrades for a roguelike FPS, so the definitions no longer live in a notepad file. |
